MacWinAnimator

The macOS Genie minimize effect — on Windows.

Minimize a window on Windows and it just shrinks away. On macOS it pours into the Dock like a genie into a lamp. MacWinAnimator brings that animation to Windows 10/11 — minimize any window and it squeezes into your taskbar, then grows back out when you restore it.

Windows 10 & 11 Runs in the tray, by the clock No admin needed Free & open source

See it in action

What it does

🧞 Genie effectThe macOS classic — windows pour into the taskbar
🔍 Scale effectWindows shrink smoothly into the taskbar instead
🌫️ Fade & slideA soft fade-out while sliding downward
↩️ Restore animationWindows grow back out of the taskbar when reopened
🕐 Lives in the trayOne small icon next to the clock — right-click for controls
🚀 Starts with WindowsOptional autostart, silently in the background

Get the app

Easiest: download the ready-made EXE — no Python needed.

⬇ Download MacWinAnimator.exe View the source code
  1. Open the latest successful Build Windows EXE run and download the MacWinAnimator-exe artifact (or grab the EXE from Releases).
  2. Double-click MacWinAnimator.exe.
  3. Look for its icon in the tray area next to the clock, bottom-right (click the ^ arrow if it's hidden). Right-click it for Settings.
  4. Minimize any window — enjoy the genie. 🧞

Prefer to build it yourself? Download the MacWinAnimator folder, install Python, and double-click build.bat — full instructions are in its README.

Good to know

  • It optionally turns off Windows' own minimize animation so the two don't overlap — and restores your setting when you quit.
  • Settings (effect, speed, autostart) save instantly to %APPDATA%\MacWinAnimator.
  • A few windows can't be animated perfectly: admin/elevated windows (unless you run it as administrator) and some fullscreen games.
